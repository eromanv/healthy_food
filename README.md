# Telegram Bot для планирования здорового питания

Бот для планирования блюд на неделю с возможностью добавления рецептов, просмотра меню и составления списка покупок.

## Установка и запуск

### 1. Установка зависимостей
```bash
uv sync
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
POSTGRES_DB=healthy_food
POSTGRES_USER=user
POSTGRES_PASSWORD=password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/healthy_food
```

### 3. Запуск базы данных
```bash
docker-compose up -d db
```

### 4. Применение миграций (опционально)
```bash
uv run alembic upgrade head
```

### 5. Запуск бота
```bash
uv run python bot.py
```

Или через Docker:
```bash
docker-compose up
```

## Функциональность

### Основные команды бота:
- `/start` - Начало работы с ботом
- `🍴 Меню` - Главное меню с дополнительными функциями

### Возможности:
1. **Добавление рецептов** - через кнопку "➕ Добавить рецепт"
   - Пошаговое добавление: название, категория, КБЖУ, ингредиенты, рецепт
   - Категории: завтрак, основное блюдо, десерт

2. **Планирование питания**
   - `🍽 Что едим сегодня` - расчет порций на день с учетом дневных норм (1800 ккал, 150г белка, 170г углеводов, 75г жиров)
     - Показывает вес каждой порции для контейнера
     - Распределение: 1 порция завтрака + 2 порции основного блюда + 1 порция десерта
   - `📅 Что готовим на неделе` - план приготовления на неделю
     - Готовка 2 раза в неделю (суббота и понедельник)
     - На каждый день готовится 3 порции
     - Возможность кликнуть на название блюда для просмотра подробного рецепта

3. **Готовка и покупки**
   - `👨‍🍳 Готовить` - что готовить в ближайший день готовки
   - `🛒 Купить` - список покупок для следующей готовки

## Дневные нормы питания

Бот использует следующие дневные нормы для расчета порций:
- **Калории**: 1800 ккал
- **Белки**: 150 грамм
- **Углеводы**: 170 грамм
- **Жиры**: 75 грамм

### Распределение по приемам пищи:
- **Завтрак**: 1 порция
- **Основное блюдо**: 2 порции
- **Десерт**: 1 порция

## Планирование готовки

Бот планирует готовку на неделю следующим образом:
- **Дни готовки**: Суббота и Понедельник
- **Количество порций**: 3 порции на каждый день
- **Суббота**: готовка на субботу, воскресенье, понедельник (9 порций)
- **Понедельник**: готовка на вторник, среду, четверг, пятницу (12 порций)

## Использование Alembic

### Создание новой миграции:
```bash
uv run alembic revision --autogenerate -m "описание_изменений"
```

### Применение миграций:
```bash
uv run alembic upgrade head
```

### Откат миграций:
```bash
uv run alembic downgrade -1
```

## Формат ингредиентов

При добавлении ингредиентов используйте формат:
```
Название ингредиента - количество единица
```

Примеры:
```
Курица - 300 г
Рис - 100 г
Лук - 1 шт
Соль - по вкусу
```

## Планирование готовки

Бот планирует готовку на субботу и понедельник:
- Суббота: готовка на 3 дня (суббота, воскресенье, понедельник)
- Понедельник: готовка на 4 дня (вторник, среда, четверг, пятница)
